# Las locuras mías: material and verification status

The library contains a generated teaching arrangement associated with this requested repertoire title. It is explicitly marked `didactic`, not a transcription of the commercial recording. Its E-centered exercise and recommended B/E/A virtual accordion are practice choices. The original recording's exact key, accordion system, registration and note timeline have not been independently verified.

The separate official video reference is [Silvestre Dangond — Las Locuras Mías](https://www.youtube.com/watch?v=LqKscPDW8Y0). The generated notes are never displayed as a synchronized transcription over this reference. No commercial audio is bundled.

Automatic playback uses the local arrangement's actual events, including note names and octaves, direction, button presses, durations and planned bellows position. The shared transport supports pause, seek, tempo, sections, A–B loops and count-in. Selecting a song restores the exercise's suggested tuning.

An exact transcription can be imported as timed JSON with provenance through the material editor. It is labeled user-supplied until independently reviewed. Unplayable pitches and incompatible simultaneous directions block automatic playback. A supplied local reference can declare filename, SHA-256 and offset; mismatches are rejected. See `public/charts/chart-template.json` for an original C–D–E example.

Remaining content work: obtain and review a permitted, timed accordion transcription against the exact recording version. Infrastructure and generated exercises do not substitute for that review.
